# Wallace Ad Engine (Private)

Automated advertising decision-support for WallaceTn.com. **Private - strategy stays here.**

- `briefs/` - weekly Adwerx campaign recommendations (auto-committed every Tuesday). Each brief shows the evidence, the 7 vetting gates, and a ready-to-paste UTM destination link for Adwerx.
- `scorecards/` - weekly campaign performance scorecards from GA4 (auto-committed every Friday) with day-30/60/90 checkpoints and SCALE / HOLD / FIX-OR-PAUSE verdicts.

Nothing is launched automatically. All spend requires human approval.
